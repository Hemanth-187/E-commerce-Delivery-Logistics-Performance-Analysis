TIME-BASED KPI ANALYSIS — NOTES
Project: E-commerce Delivery & Logistics Performance Analysis

1. Delivery Duration
Definition:
The actual shipping duration recorded in the dataset.

Column used:
Days for shipping (real)

Unit:
Days

Calculation:
Delivery Duration = Days for shipping (real)

Average observed value:
3.5 days (rounded to one decimal place)

Limitation:
The dataset does not contain the actual customer delivery timestamp. Therefore, this KPI uses the recorded actual shipping-duration field as a proxy.

2. Average Delay
Definition:
The difference between actual shipping duration and scheduled shipping duration.

Columns used:
Days for shipping (real)
Days for shipment (scheduled)

Calculation:
Delay Days = Days for shipping (real) - Days for shipment (scheduled)

Interpretation:
Positive value = took longer than scheduled.
Zero = matched the scheduled duration.
Negative value = completed faster than scheduled.

Average observed value:
Use the value displayed in the final KPI Summary sheet. The exact average may be around 0.57 days, which rounds to 0.6 days at one decimal place.

3. Order Processing Time
Definition used in this analysis:
Elapsed time between the order date and shipping date, based on available timestamps.

Columns used:
order date (DateOrders)
shipping date (DateOrders)

Calculation:
Order Processing Time = shipping date (DateOrders) - order date (DateOrders)

Average observed value:
3.5 days (rounded to one decimal place)

Limitation:
Actual warehouse processing timestamps are unavailable. This measure represents order-to-shipping elapsed time and should not be interpreted as a direct measure of warehouse processing alone.

General Notes:
- Date columns were converted to datetime format before calculation.
- Invalid/unparseable timestamps, if any, should be checked before interpreting results.
- KPI values are rounded for presentation; calculations should use the original precision.
